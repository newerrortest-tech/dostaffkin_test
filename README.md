# Dostaffkin — lesson2

Главная страница учебного проекта по уроку «Основы верстки и верстка главной страницы».

## Запуск
Распакуйте архив и откройте index.html в браузере. Сохраняйте структуру папок: styles, fonts, images.

## Состав
- index.html — разметка главной страницы.
- styles/base.css — шрифты, общие стили, шапка и кнопки.
- styles/base_adaptive.css — адаптив шапки.
- styles/index.css — стили главной.
- styles/index_adaptive.css — адаптив главной.
- fonts — три предоставленных начертания Roboto.
- images/main-image.png — исходная иллюстрация, извлечённая из предоставленного макета Figma, с исходным водяным знаком.

## Объём урока
Страницы order.html и track.html не входят в этот проект главной страницы. Ссылки на них сохранены из кода урока для последующего продолжения: сейчас переходы на них не работают.

## Что уточнено при сборке
Использован h1 для заголовка, разрешено масштабирование страницы на мобильном, сохранён видимый фокус ссылок. Для слоёв задан isolation, для flex-колонок явно задано сжатие.

## Проверка
Проверены наличие подключённых CSS, шрифтов и изображения, структура HTML и валидность файлов шрифтов. Визуальная проверка в браузере в среде сборки не выполнена. Перед сдачей откройте страницу на компьютере и проверьте её при ширинах 1440, 1024, 570 и 375 px.
